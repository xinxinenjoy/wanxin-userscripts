浏览器与插件安装

  • 请使用电脑端常规浏览器打开本页。 推荐 Chrome、Microsoft Edge、Firefox、360 等； 微信、企业微信、QQ 等应用内置浏览器无法正常安装浏览器扩展。
  • 请选择与你当前浏览器对应的 Tampermonkey。 360 等 Chromium 内核浏览器通常可优先尝试 Chrome 版。
  • 如果使用 CRX 离线安装，先开启浏览器“开发者模式”。 再进入扩展管理页按 Crx搜搜说明安装；在线安装正常时不需要这一步。

关键权限设置：Chrome / Edge / 360 用户必看

  • Tampermonkey 5.3+ 在 Chromium 浏览器中需要额外的用户脚本执行权限。 Chrome 138+ 可在 Tampermonkey 的“管理扩展程序”页面开启“允许用户脚本”； 如果没有这个开关，则开启浏览器扩展页面的“开发者模式”。
  • Edge 或其他 Chromium 内核浏览器同样需要满足上述权限条件。 不同浏览器的开关位置可能略有差异，设置完成后建议刷新目标网页。
  • 脚本安装成功但完全不运行时，优先检查这一项。 这是目前 Chromium 浏览器最常见的首次使用遗漏。

Tampermonkey 内部设置

  • 确认 Tampermonkey 总开关和目标脚本开关均处于启用状态。 建议把 Tampermonkey 固定到浏览器工具栏，方便随时查看当前页面是否有脚本运行。
  • 建议保留用户脚本自动更新。 新版 Tampermonkey 将“检查更新”和“自动安装更新”逐步分开； 如果设置中出现“Automatic installation / 自动安装”，希望全自动更新时请保持开启。
  • 一般不需要修改高级执行模式。 Content Script API、沙箱等高级选项保持默认即可，除非某个脚本明确要求调整。

安装脚本与常见问题

  1. 安装并启用 Tampermonkey，完成上面的用户脚本权限设置。
  2. 进入脚本中心，在需要的脚本卡片中点击“立即安装”。
  3. Tampermonkey 打开确认页后，核对脚本名称并点击“安装”。
  4. 打开脚本对应的网站并刷新页面即可使用。
  • 点击“立即安装”后只是下载文件或显示代码： 先检查 Tampermonkey 是否已安装并启用，以及当前浏览器是否允许用户脚本。
  • 新版暂时没有检测到： 等待 GitHub Actions 与 Cloudflare Pages 部署完成后再检查， 或重新点击“立即安装”覆盖安装最新版。

公司电脑或受统一策略管理的浏览器可能禁止安装第三方扩展。 如果浏览器提示“由组织管理”或扩展安装被禁用，需要先确认本机策略。
